## Required Tools (Understood and Confirmed)
To successfully complete this task, the following must already be available:

Node.js (LTS version)
→ Required to run JavaScript, Expo CLI, and project tooling.

Visual Studio Code (VS Code)
→ Recommended IDE for writing and managing the project code.

Operating System
→ macOS, Linux, or Windows (all supported).

Expo Go (Physical Device)
→ Installed on:

Android device or

iOS device

These tools are described as essential, meaning future tasks depend on them.
### Steps to Install Expo Go (Clearly Understood)
Visit the official Expo Go page
👉 https://expo.dev/go

Select the latest SDK version

Install Expo Go based on your device:

Android → Google Play Store

iOS → Apple App Store

Open the Expo Go app

Create an Expo account or log in if you already have one

These steps ensure the device is ready to run React Native apps instantly.
